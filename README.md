# Doodle Den Academy — Ranchi

> **Holistic Learning & Activity Center for Children (Ages 2–11 Years)**  
> *Where Imagination Takes Flight! Learn, explore, create, and grow under one roof.*

Official Instagram: [@doodleden_academy](https://www.instagram.com/doodleden_academy/)

---

## 🌟 Concept & Philosophy
**Doodle Den Academy** in Ranchi is designed as an all-in-one space to help children learn, explore, create, and grow under one roof, eliminating the need for parents to commute between multiple separate hobby classes across town.

### 4 Core Developmental Pillars:
1. **Creativity & Arts**: Pottery, clay modeling, canvas painting, recycled craft creations, and toddler sensory play.
2. **Movement & Sports**: Junior gymnastics, balance beams, animal yoga, and active agility obstacle courses.
3. **Future Skills**: AI & robotics basics, screen-smart tinkering labs, Lego mechanics, and algorithmic thinking.
4. **Performing Arts**: Children's theater, storytelling, voice modulation, puppetry, and musical percussion & dance.

## 🚀 Key Website Features
- **Modern & Playful UI**: Built with React 18, Vite, Tailwind CSS, custom bubbly shadows, and Google Fonts (`Fredoka` & `Plus Jakarta Sans`).
- **Interactive Programs Explorer**: Filter activities by Pillar (Creativity, Movement, Future Skills, Performing Arts) and by Age Group (2–4 yrs, 4–7 yrs, 6–11 yrs).
- **Free Trial Class Booking Modal**: Accessible modal form for parents to schedule a trial session, with instant verification and direct 1-tap WhatsApp message forwarding.
- **Weekly Schedule & Timetable**: Interactive tabs for Weekday morning playgroups & after-school slots vs Weekend bootcamps.
- **Activity Showcase Gallery**: Filterable snapshot cards of real den activities.
- **Direct WhatsApp & Instagram Integration**: Pre-filled chat prompts and verified Instagram profile linking.
- **Safety & Reassurance Standards**: Highlights campus hygiene, CCTV, pediatric first-aid, and certified staff.
- **Authentic Testimonials**: Reviews from Ranchi localities (Morabadi, Kanke Road, Ashok Nagar).
- **Parent FAQs Accordion**: Expandable answers addressing batch sizes, customized multi-pillar passes, and trial policies.

## 🛠️ Development & Running Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm

### 1. Start Local Development Server
```bash
npm run dev
```
The server will start at `http://localhost:3000` with instant Hot Module Replacement (HMR).

### 2. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory ready to deploy to Vercel, Netlify, Cloudflare Pages, or Firebase Hosting.

### 3. Preview Production Build
```bash
npm run preview
```
